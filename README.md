# 🧭 旅行足跡地圖 Travel Trace Map

用手機 GPS 記錄你走過的路，在地圖上留下軌跡，並可下載成 PDF。純前端網頁，不需要安裝、不需要伺服器。

## 功能

- **走過就留下痕跡**：按「開始記錄」後持續定位，自動把路線畫在地圖上（過濾 GPS 抖動與低精度定位點）
- **城市切換**：上方選單依國家分組，可選東京、大阪、京都、名古屋、北海道、札幌、福岡、沖繩、首爾、釜山、濟州島、慶州、台北、台中、台南、高雄、花蓮、香港、澳門、曼谷、清邁、新加坡、河內、胡志明市
- **飛行段**：同一段記錄中相鄰兩點相距超過 100 公里會自動畫成 ✈ 虛線弧線；搭機時沒記錄也能用「新增飛行段」手動補上（例如台北 → 釜山）
- **停留點與站名**：在同一處停留超過設定時間（預設 15 分鐘）會自動標記，並用 OpenStreetMap 查出附近的車站或地名，盡量顯示中文（例如「西面站（서면역）・停留 1 小時 20 分」）
- **自訂頭像**：停留點的圖示可換成自己的照片或任一表情符號
- **多段旅程管理**：每次記錄存成一段旅程，可顯示/隱藏、縮放、刪除，資料保存在瀏覽器（localStorage）
- **下載軌跡 PDF**：可選範圍「目前城市／目前地圖畫面／依軌跡自動縮放」，含標題、總距離、日期與圖例
- **GPX 匯入/匯出**：可匯入其他 App 的 GPX 軌跡，或把旅程匯出成 GPX
- **模擬旅程**：在電腦上沒有 GPS 時，可用來試玩與測試 PDF

## 使用方式

定位功能需要 **HTTPS**（或 `localhost`）。

### 本機執行

```bash
python3 -m http.server 8000
```

然後開啟 http://localhost:8000

### 部署到 GitHub Pages（手機上使用）

Repo → Settings → Pages → Source 選擇分支與根目錄，儲存後即可用 `https://<帳號>.github.io/<repo>/` 在手機開啟。

## 新增城市

在 `app.js` 最上方的 `CITY_GROUPS` 加一行即可，例如：

```js
nara: { name: '奈良', bounds: [[34.62, 135.75], [34.73, 135.88]] },
```

`bounds` 為 `[[南緯, 西經], [北緯, 東經]]`。

## 注意事項

- 站名查詢使用 OpenStreetMap 的 Overpass 與 Nominatim 免費服務，需要連網；記錄當下不需要網路，之後連網會自動補查。中文名稱取決於 OSM 的資料，沒有中文時會顯示當地名稱或英文。

- 瀏覽器在螢幕關閉或切到背景時可能暫停定位；記錄期間程式會嘗試保持螢幕常亮（Wake Lock）。
- 軌跡只存在目前這台裝置的瀏覽器中，清除瀏覽資料會一併刪除；建議重要旅程匯出 GPX 備份。

## 技術

Leaflet 1.9.4、jsPDF 2.5.1。PDF 由程式自行拼接地圖圖磚並繪製軌跡，再輸出成 A4 PDF（中文文字畫在圖上，不會亂碼）。
