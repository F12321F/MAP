# 🧭 旅行足跡地圖 Travel Trace Map

用手機 GPS 記錄你走過的路，在地圖上留下軌跡，並可下載成 PDF。純前端網頁，不需要安裝、不需要伺服器。

## 功能

- **走過就留下痕跡**：按「開始記錄」後持續定位，自動把路線畫在地圖上（過濾 GPS 抖動與低精度定位點）
- **地圖範圍切換**：亞洲／歐洲／美洲
- **多段旅程管理**：每次記錄存成一段旅程，可顯示/隱藏、縮放、刪除，資料保存在瀏覽器（localStorage）
- **下載軌跡 PDF**：可選範圍「亞洲／歐洲／美洲／依軌跡自動縮放」，含標題、總距離、日期與圖例
- **GPX 匯入/匯出**：可匯入其他 App 的 GPX 軌跡，或把旅程匯出成 GPX
- **模擬旅程**：在電腦上沒有 GPS 時，可用來試玩與測試 PDF

## 使用方式

定位功能需要 **HTTPS**（或 `localhost`）。

### 本機執行

```bash
python3 -m http.server 8000
```

然後開啟 http://localhost:8000

### 部署到 GitHub Pages（手機上使用）

Repo → Settings → Pages → Source 選擇分支與根目錄，儲存後即可用 `https://<帳號>.github.io/<repo>/` 在手機開啟。

## 注意事項

- 瀏覽器在螢幕關閉或切到背景時可能暫停定位；記錄期間程式會嘗試保持螢幕常亮（Wake Lock）。
- 軌跡只存在目前這台裝置的瀏覽器中，清除瀏覽資料會一併刪除；建議重要旅程匯出 GPX 備份。

## 技術

Leaflet 1.9.4、jsPDF 2.5.1。PDF 由程式自行拼接地圖圖磚並繪製軌跡，再輸出成 A4 PDF（中文文字畫在圖上，不會亂碼）。
